#Présentation en français

Bienvenue !
Vous consultez la documentation du projet GamesDoneQuack, un projet de site web inspiré de GoodReads, ImDB, LetterBox et tous les sites qui réunissent une communauté autour d'une pratique culturelle. L'idée est de concevoir un espace de discussion, de recommandation et parfois de coordination autour du jeu vidéo.


###Outils utilisés

Spring Tools pour coder le backend
VS Code pour coder le frontend
PgAdmin pour gérer la base de données
Git pour le contrôle des versions


###Spécifications techniques

L'application est construite sur une stack Spring Boot / Angular classique. Le code du backend Spring Boot se trouve dans le sous-projet 'Backend', et le Frontend Angular dans le sous-projet 'Frontend'.


JAVA : 23
Spring Framework :  3.5.6
Spring Security : 6.5.5
Angular : 17
Postgresql : 17.5
Lombok : 1.18.32
Mapstruct : 1.5.5


###Lancement rapide avec Docker

-Ouvrez un terminal
-Se placer dans le dossier `GamesDoneQuack`
-Entrez la commande `docker compose up` 
-Vous avez accès à l'application depuis votre navigateur avec l'URL : `http://localhost:4200/`


#Presentation in English

Welcome!
You are reading the documentation of the GamesDoneQuack project, a website inspired by GoodReads, ImDB, LetterBox and other places reuniting communities around a cultural interest. The idea is to conceive a place for discussion, recommandations, and sometimes coordination around video games.

The application is built on a classic Java SpringBoot / Angular stack. Backend Code is stored in sub-project 'Backend' and Frontend Angular code can be found in sub-project 'Frontend'.

#QuickStart

-Open a terminal
-Go in the `GamesDoneQuack` directory
-Run the command `docker compose up`
-You can now access the application from your browser with the URL : `http://localhost:4200/`
